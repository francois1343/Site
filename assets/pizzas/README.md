# Bibliotheque photo des pizzas

47 images de pizza sont copiees ici depuis Downloads. Les originaux restent dans Downloads.
Sept autres fichiers Gemini presents dans ce dossier etaient des visuels sans rapport avec les pizzas et n'ont pas ete copies.

Les photos photo-01 a photo-47 sont proposees dans la galerie de l'administration. Elles ne sont associees automatiquement a aucun article : le responsable les choisit apres avoir compare la garniture et la photo. Les futures images peuvent etre importees depuis l'administration et sont conservees dans le dossier de donnees local de La Mouna.
